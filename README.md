# Формы отклика — Карьерная платформа

Сервис для создания и управления формами отклика студентов на стажировки и мероприятия.

## Возможности

- **Конструктор форм** — менеджер самостоятельно создаёт формы из 9 типов полей
- **Drag & Drop** — изменение порядка полей перетаскиванием
- **Публикация по ссылке** — каждая форма получает уникальную ссылку
- **Сбор ответов** — просмотр и экспорт ответов в CSV
- **Валидация** — проверка обязательных полей и форматов (email, телефон)
- **Управление** — активация/деактивация форм, дублирование, удаление

## Типы полей

- Текст (короткий)
- Длинный текст (textarea)
- Email
- Телефон
- Число
- Дата
- Выпадающий список
- Один вариант (radio)
- Несколько вариантов (checkbox)

## Запуск

```bash
# Установка зависимостей
npm install

# Запуск сервиса
npm start
```

Сервис будет доступен по адресу: **http://localhost:3000**

### Настройка порта

```bash
PORT=8080 npm start
```

## Использование

### Админ-панель

Перейдите по адресу: **http://localhost:3000/admin**

1. Нажмите "Создать форму"
2. Заполните название и описание
3. Добавьте поля с помощью панели справа
4. Настройте каждое поле (вопрос, подсказка, варианты, обязательность)
5. Сохраните форму
6. Скопируйте ссылку и отправьте студентам

### Публичная форма

Студенты переходят по ссылке вида: `http://localhost:3000/form/{id}`

Заполняют форму и отправляют ответы.

### Просмотр ответов

В админ-панели нажмите на иконку графика рядом с формой для просмотра ответов.

Доступен экспорт в CSV для анализа в Excel/Google Sheets.

## Технологии

- **Frontend:** React 18, TypeScript, Tailwind CSS
- **Роутинг:** React Router
- **Иконки:** Lucide React
- **Сервер:** Express.js
- **Хранилище:** localStorage (полная автономность)

## Хранение данных

Все данные хранятся в localStorage браузера. Это обеспечивает:
- Полную автономность (без внешних зависимостей)
- Простоту развёртывания
- Мгновенное сохранение

**Важно:** данные привязаны к браузеру и устройству. Очистка localStorage приведёт к потере данных.
